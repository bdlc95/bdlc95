🚀 Projetos em destaque

🧠 AI Code Reviewer · Java + React + IA

Aplicação full stack que recebe trechos de código e devolve sugestões de melhoria com base em SOLID, Clean Code, legibilidade e manutenção.

Front-end: interface responsiva em React, TypeScript e Vite, integrada à API REST.

🎵 Plataforma de blog musical · Em desenvolvimento

Estou construindo uma plataforma para publicar resenhas de álbuns e bandas, com autenticação, papéis de usuário, posts e comentários. A aplicação usa Next.js, TypeScript, PostgreSQL, Prisma e NextAuth. A apresentação do projeto está no portfólio enquanto ele está em desenvolvimento.

🔗 Sistema de microsserviços Java · Spring Boot + OpenFeign

Desenvolvi ms-cliente e ms-produto como serviços independentes, cada um com sua própria persistência em PostgreSQL. Explorei endpoints REST, arquitetura Controller → Service → Repository e comunicação síncrona entre serviços com OpenFeign.

🗄️ Sistema com persistência dupla · PostgreSQL + MongoDB

Ampliei um sistema de vendas para combinar dados relacionais com registros de operações em documentos. Usei JPA/Hibernate, MongoDB e JUnit 5 para implementar e testar o fluxo.
